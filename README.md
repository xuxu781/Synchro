## 系统概述

### 产品简介

Synchro 企业官网系统是一款专为企业、团队打造的专业级官方网站管理系统。系统采用现代化的设计理念，提供完整的企业信息展示、产品管理、团队介绍、客户互动等功能模块，帮助企业快速建立专业的网络形象。

### 系统特点

#### 企业级架构设计

系统采用模块化架构设计，代码结构清晰，易于维护和扩展。核心功能包括：

- **MVC分层架构**：业务逻辑与展示层分离，便于二次开发
- **PDO数据库抽象层**：支持多种数据库操作，防止SQL注入
- **会话安全机制**：IP绑定、会话超时、CSRF防护等多重安全保障
- **权限控制系统**：基于角色的访问控制（RBAC），精细化权限管理

#### 完整的功能模块

前台展示模块：
- 首页轮播图展示
- 公司简介与统计数据
- 企业文化展示
- 行为准则展示
- 产品分类展示与详情页
- 业务领域介绍
- 发展历程时间线
- 团队成员介绍与防伪查询
- 在线留言系统（邮箱验证码）
- 社交链接展示

后台管理模块：
- 可视化仪表盘
- 媒体资源管理
- 内容管理（轮播图、简介、文化等）
- 产品与业务管理
- 产品更新日志管理
- 留言管理
- 用户与权限管理
- 操作日志与安全日志
- SEO优化设置
- 系统配置管理

#### 安全特性

- **登录安全**：验证码验证、登录失败记录、账户状态检测
- **会话保护**：IP地址绑定、会话超时自动退出、会话固定攻击防护
- **CSRF防护**：所有表单提交均需验证CSRF令牌
- **操作审计**：完整的操作日志记录，便于追溯
- **安全日志**：记录登录失败、权限拒绝、未授权访问等安全事件
- **邮件告警**：高危安全事件自动邮件通知管理员

## 环境要求

### 支持的操作系统

本系统支持以下操作系统环境：

| 操作系统 | 支持状态 | 说明 |
|----------|----------|------|
| Linux（CentOS/Ubuntu/Debian等） | ✅ 推荐 | 生产环境首选，稳定性高 |
| Windows Server | ✅ 支持 | 需配置IIS或Apache |
| macOS | ✅ 支持 | 适合本地开发测试 |

### 支持的Web服务器

| Web服务器 | 支持状态 | 说明 |
|-----------|----------|------|
| Nginx | ✅ 推荐 | 性能优异，资源占用低 |
| Apache | ✅ 支持 | 兼容性好，自动支持.htaccess |
| IIS | ✅ 支持 | Windows环境，需配置URL重写 |
| OpenResty | ✅ 支持 | 基于Nginx，性能更强 |

### 支持的PHP运行环境

| 运行环境 | 支持状态 | 说明 |
|----------|----------|------|
| PHP-FPM | ✅ 推荐 | Nginx标配，性能优秀 |
| mod_php | ✅ 支持 | Apache模块方式运行 |
| FastCGI | ✅ 支持 | IIS环境推荐使用 |

### 服务器环境配置

| 环境项 | 最低要求 | 推荐配置 |
|--------|----------|----------|
| PHP版本 | 7.4.0 | 8.0+ |
| MySQL版本 | 5.7 | 8.0 |
| 内存限制 | 128M | 256M+ |
| 上传限制 | 10M | 50M+ |

### 推荐运行环境组合

| 场景 | 操作系统 | Web服务器 | PHP | 数据库 |
|------|----------|-----------|-----|--------|
| 生产环境（推荐） | CentOS 7+ | Nginx | PHP 8.0+ (FPM) | MySQL 8.0 |
| 生产环境（备选） | Ubuntu 20+ | Nginx | PHP 8.0+ (FPM) | MySQL 8.0 |
| Windows服务器 | Windows Server | IIS/Apache | PHP 8.0+ | MySQL 8.0 |
| 本地开发 | Windows/macOS | Apache/Nginx | PHP 7.4+ | MySQL 5.7+ |

## 宝塔面板安装教程

### 第一步：安装宝塔面板

如果您尚未安装宝塔面板，请按以下步骤操作：

#### Linux系统安装

登录服务器SSH，执行以下命令：

**CentOS/RedHat系统：**
```bash
yum install -y wget && wget -O install.sh https://download.bt.cn/install/install_6.0.sh && sh install.sh ed8484bec
```

**Ubuntu/Debian系统：**
```bash
wget -O install.sh https://download.bt.cn/install/install-ubuntu_6.0.sh && sudo bash install.sh ed8484bec
```

安装完成后，系统会显示面板访问地址、用户名和密码，请妥善保存。

#### Windows系统安装

1. 访问宝塔官网下载Windows版本安装包
2. 双击运行安装程序
3. 按提示完成安装
4. 安装完成后会自动打开面板

### 第二步：配置运行环境

登录宝塔面板后，需要安装以下软件：

#### 安装Web服务器

推荐选择 **Nginx** 或 **Apache**：

1. 点击左侧菜单【软件商店】
2. 找到【Nginx】或【Apache】
3. 点击【安装】
4. 选择稳定版本，点击【提交】

#### 安装PHP

1. 点击左侧菜单【软件商店】
2. 找到【PHP】
3. 选择 **PHP 8.0** 或 **PHP 7.4**
4. 点击【安装】
5. 安装完成后，点击【设置】

#### 配置PHP扩展

安装PHP后，需要安装必需扩展：

1. 在PHP设置页面，点击【安装扩展】
2. 找到并安装以下扩展：
   - opcache（性能优化）
   - redis（可选，缓存加速）
   - fileinfo（文件信息）
   - imagemagick（图像处理，可选）

#### 安装MySQL

1. 点击左侧菜单【软件商店】
2. 找到【MySQL】
3. 选择 **MySQL 5.7** 或 **MySQL 8.0**
4. 点击【安装】

### 第三步：创建网站

#### 添加站点

1. 点击左侧菜单【网站】
2. 点击【添加站点】
3. 填写以下信息：
   - **域名**：输入您的域名（如 lintuyue.com）
   - **根目录**：选择网站存放目录（如 /www/wwwroot/lintuyue.com）
   - **PHP版本**：选择已安装的PHP版本
   - **数据库**：选择【MySQL】，会自动创建数据库
4. 点击【提交】创建站点

#### 记录数据库信息

创建站点后，系统会显示数据库信息：

- 数据库名
- 数据库用户名
- 数据库密码

请记录这些信息，安装时需要使用。

### 第四步：上传程序文件

#### 方式一：通过宝塔文件管理

1. 点击左侧菜单【文件】
2. 进入网站根目录
3. 点击【上传】按钮
4. 选择程序压缩包上传
5. 上传完成后，右键选择【解压】

#### 方式二：通过FTP上传

1. 点击左侧菜单【FTP】
2. 创建FTP账户
3. 使用FTP客户端连接服务器
4. 上传程序文件到网站根目录

### 第五步：设置目录权限

通过宝塔文件管理器设置权限：

1. 进入网站根目录
2. 选中以下目录：
   - uploads
   - lty-admin/uploads
   - lty-admin/config
   - logs
3. 右键选择【权限】
4. 设置为 **755** 或 **777**
5. 勾选【应用到子目录】
6. 点击【确定】

### 第六步：配置伪静态

#### Nginx配置

1. 点击左侧菜单【网站】
2. 找到对应站点，点击【设置】
3. 点击左侧【伪静态】
4. 输入以下规则：

```nginx
location / {
    try_files $uri $uri/ /index.php?page=$uri&$args;
}

location ~ ^/api/ {
    try_files $uri $uri/ $uri/;
}

location ~ ^/lty-admin/ {
    try_files $uri $uri/ $uri/;
}

location ~ /config.php {
    deny all;
}

location ~ \.(log|sql|bak|old|tmp)$ {
    deny all;
}

location ~ /\. {
    deny all;
}
```

5. 点击【保存】

**配置说明：**

| 规则 | 说明 |
|------|------|
| `location /` | 主路由规则，将 `/team`、`/contact` 等请求转发到 `index.php` |
| `location ~ ^/api/` | API 目录直接访问文件，不经过路由重写 |
| `location ~ ^/lty-admin/` | 后台目录直接访问文件，不经过路由重写 |
| `location ~ /config.php` | 禁止访问配置文件，安全保护 |
| `location ~ \.(log\|sql\|...)$` | 禁止访问敏感文件类型 |

#### Apache配置

Apache服务器会自动读取程序根目录的 `.htaccess` 文件，无需额外配置。

如果 Apache 伪静态不生效，请检查：

1. **确认 mod_rewrite 已启用**
   ```bash
   # 查看已加载模块
   apachectl -M | grep rewrite
   
   # 如未启用，执行以下命令
   a2enmod rewrite
   systemctl restart apache2
   ```

2. **确认 AllowOverride 设置**
   
   在 Apache 配置文件中，确保网站目录允许 `.htaccess` 覆盖：
   ```apache
   <Directory "/var/www/html">
       AllowOverride All
   </Directory>
   ```

3. **重启 Apache 服务**
   ```bash
   systemctl restart apache2
   ```

### 第七步：运行安装向导

#### 访问安装页面

在浏览器中访问：


点击【开始安装】，系统将自动：

- 创建管理员账户
- 生成配置文件

**步骤七：安装完成**

安装成功后，您可以：
- 点击【进入前台】查看网站
- 点击【进入后台】开始管理

### 第八步：安全加固

#### 删除安装文件

安装完成后，建议删除或重命名安装文件：

```bash
# 删除安装文件
rm -f /www/wwwroot/您的域名/install.php

# 或重命名
mv /www/wwwroot/您的域名/install.php /www/wwwroot/您的域名/install.php.bak
```

#### 配置SSL证书

1. 点击左侧菜单【网站】
2. 找到对应站点，点击【设置】
3. 点击左侧【SSL】
4. 选择【Let's Encrypt】
5. 勾选域名，点击【申请】
6. 申请成功后，开启【强制HTTPS】

#### 设置防火墙

1. 点击左侧菜单【安全】
2. 放行必要端口：
   - 80（HTTP）
   - 443（HTTPS）
   - 22（SSH）
   - 宝塔面板端口（默认8888）
3. 其他端口建议关闭

## 系统配置

### 基础配置文件

系统配置文件位于 `config.php`，包含以下核心设置：

```php
define('SITE_NAME', '团队官网');        // 网站名称
define('SITE_URL', 'http://localhost'); // 网站地址
define('ADMIN_EMAIL', 'admin@example.com'); // 管理员邮箱
define('VERSION', '1.0.0');             // 系统版本
```

### 数据库配置

数据库配置文件位于 `lty-admin/config/database.php`：

```php
define('DB_HOST', 'localhost');     // 数据库主机
define('DB_NAME', 'database_name'); // 数据库名
define('DB_USER', 'username');      // 数据库用户名
define('DB_PASS', 'password');      // 数据库密码
define('DB_CHARSET', 'utf8mb4');    // 字符集
```

### 时区设置

系统默认使用中国时区：

```php
date_default_timezone_set('Asia/Shanghai');
```

如需修改，请参考PHP支持的时区列表。

## 常见问题

### 安装问题

**Q：环境检测不通过怎么办？**

A：请检查以下项目：
- PHP版本是否达到7.4以上
- 必需扩展是否已安装
- 目录权限是否正确设置

**Q：数据库连接失败？**

A：请确认：
- 数据库服务是否启动
- 数据库信息是否正确
- 数据库用户是否有足够权限

**Q：安装后无法访问？**

A：请检查：
- 伪静态规则是否正确配置
- 网站根目录是否正确
- PHP是否正常运行

### 功能问题

**Q：团队成员、联系我们页面不显示或跳转首页？**

A：这是伪静态规则未正确配置导致的。系统使用 URL 重写将 `/team`、`/contact` 等请求转发到对应的 PHP 文件。

**Nginx 解决方案：**
1. 登录宝塔面板
2. 点击【网站】→ 找到站点 → 点击【设置】
3. 点击左侧【伪静态】
4. 确保规则正确：
   ```nginx
   location / {
       try_files $uri $uri/ /index.php?page=$uri&$args;
   }
   
   location ~ ^/api/ {
       try_files $uri $uri/ $uri/;
   }
   
   location ~ ^/lty-admin/ {
       try_files $uri $uri/ $uri/;
   }
   ```
5. 点击【保存】并清除浏览器缓存

**Apache 解决方案：**
1. 确认 `.htaccess` 文件存在于网站根目录
2. 确认 Apache 已启用 `mod_rewrite` 模块
3. 确认虚拟主机配置中 `AllowOverride` 设置为 `All`

**Q：图片上传失败？**

A：可能原因：
- uploads目录权限不足
- 上传文件超过服务器限制
- 图片格式不支持

解决方案：
```bash
# 设置目录权限
chmod -R 755 uploads/
chown -R www:www uploads/
```

**Q：邮件发送失败？**

A：请检查：
- SMTP服务器配置是否正确
- 邮箱账号密码是否正确
- 服务器是否开放相应端口（25、465、587）

**Q：验证码不显示？**

A：请检查：
- PHP GD扩展是否安装
- PHP是否支持FreeType

**Q：QQ邮箱头像不显示？**

A：系统会自动识别 `数字@qq.com` 格式的邮箱并获取QQ头像。请确认：
- 邮箱格式是否正确
- QQ用户是否设置了公开头像

### 性能问题

**Q：网站访问慢？**

A：优化建议：
- 开启OPcache缓存
- 使用CDN加速静态资源
- 优化图片大小
- 启用Gzip压缩

**Q：后台加载慢？**

A：建议：
- 清理操作日志
- 优化数据库
- 升级服务器配置
